## 1. 개요

### 1.1 기준

- 디자인 시안(claude.ai 캔버스, 비공개): https://claude.ai/artifact/DoQQ31jnCJUKzDzujcibRo
- 시안은 화면 구성과 동작을 보여 주는 참고 자료이고, **색·글자·간격 같은 수치는 이 문서가 기준**이다. 시안과 이 문서가 다르면 이 문서를 따른다.
- 화면별 요구사항은 `docs/기능요구사항서.md`를 따른다. 시안은 기능요구사항서의 와이어프레임을 대체한다.

### 2.4 색 사용 규칙

- **선택 상태는 보라색**: 유형 선택, 필터 칩, 정렬, 기간 선택에 연보라(`soft`) 배경 + 보라(`primary`) 2px 테두리 + 진보라(`soft-text`) 글자를 쓴다. 하단 탭은 선택된 탭의 아이콘과 글자를 연보라색 배경으로 감싼다.
- **색만으로 구분하지 않는다**: 알러지·주의는 경고 아이콘 + "주의" 글자, 유형은 아이콘 + 이름, 계획 칸은 점선 + "예정" 배지를 함께 쓴다.
- **음식 반응 배지**: 매우 좋아함 `primary` 배경 + `on-primary` 글자, 좋아함 `soft` 배경 + `soft-text` 글자, 보통 회색(`subtle`: `#F3F1F8` / 다크 `#2A2733`) 배경 + `text` 글자, 거부 `danger-soft` 배경 + `danger-text` 글자. 연한 색은 배경으로만 써서 글자 대비를 지킨다. 테두리가 없어 선택 상태(2px 보라 테두리)와 구분되고, 경고 아이콘이 없어 "주의" 배지와 구분된다.
- **명도 대비**: 글자는 배경과 4.5:1 이상.

### 5.1 홈 (2026-11-25 요약과 바로 기록)

- 모바일 홈 상단에 새싹과 MyBabyLog를 본문과 같은 배경색으로 표시하고 설정 버튼을 오른쪽에 둔다. 아이 정보 화면은 홈으로와 설정 버튼을 제목 위에 둔다. 식사·성장·수면·준비 화면의 헤더에는 설정 버튼을 표시하지 않는다.
- 상단 가운데에 64px 원형 사진, 이름, 월령, 작은 생년월일을 각각 한 줄로 표시한다. 이름·월령은 굵게, 두 줄의 간격은 5px이다. 사진을 누르면 아이 정보 수정 화면이 열린다.
- 모바일·PC 모두 오늘의 식단 → 오늘의 기록 → 어젯밤 수면 → 준비 목록 → 최근 측정 순서로 표시한다. 앞의 두 항목은 카드, 뒤의 세 항목은 구분선이 있는 요약 행이다.
- 섹션 제목은 15px/700, 컬러 블록 아이콘은 34px다. 요약 행 오른쪽 값은 모두 14px/400이다.
- 식단에는 굵은 끼니 이름, 음식·레시피 이름, 글자만 있는 먹음·예정 태그를 둔다. 오늘의 기록은 단어·행동·표정 순으로 기록이 있는 유형의 최신 항목을 한 줄씩 보여 주고, 같은 유형이 여러 건이면 해당 날짜의 타임라인으로 연결한다.
- 비어 있을 때는 식단·성장·수면·측정의 기존 기록하기 버튼을 제목 아래에 표시한다. 데이터가 있으면 식단·성장은 제목 오른쪽에 “＋ 추가”를 두고, 총 수면과 최신 측정값은 각각 기존 수면 수정과 새 측정 입력으로 연결한다.
- 성장 선택 시트는 단어·행동·표정 3개를 한 줄로 표시한다. 키·몸무게는 최근 측정 카드에서 기록한다.
- 식단 선택 시트는 미기록 끼니만 표시한다. 아침·점심·저녁·간식 4개일 때 2×2, 3개면 한 줄, 2개면 한 줄, 1개면 전체 폭이다. 모두 기록했으면 헤더 추가 버튼을 숨긴다. 선택하면 해당 끼니 입력을 바로 연다.
- 선택 시트는 취소·Esc·바깥 영역으로 닫으며, 닫으면 원래 버튼으로 초점이 돌아온다.

### 5.2 성장 > 기록 (2026-11-19 시안 승인)

- 위쪽 “누적 기록”에 단어·행동·표정·처음 먹은 음식 카드 4개를 둔다. 중복된 “전체 보기” 버튼은 제거한다 (2026-11-23). 별도 유형 칩 줄은 없앤다.
- 모바일과 좁은 태블릿은 2×2, 각 카드는 “아이콘 + 단어 2개” 한 줄형·높이 52px이다. 숫자는 15px/700, 이름·단위는 13px. 아주 좁은 화면(360px 이하)에서는 아이콘을 숨겨 전체 이름을 유지한다.
- 1,024px 이상은 카드 4개를 한 줄로, 이름 아래에 24px 누적 개수를 표시한다. 공간이 부족하면 이름은 자연스럽게 줄바꿈한다.
- 카드 선택은 한 유형만 보기이며, 선택된 카드를 다시 누르면 유형만 전체로 돌린다. 선택한 기간·직접 지정한 날짜는 유지한다. 누적 개수는 기간과 관계없이 고정된다.
- 아래에는 전체 기간 / 이번 달 / 지난 달 / 직접 선택만 한 줄에서 공간에 맞춰 줄바꿈한다. PC의 별도 왼쪽 필터 상자도 없앤다.
- 처음 먹은 음식은 처음 먹은 날이 기록된 음식 기준이다. 요약 카드·기록 목록의 아이콘은 노란 계열, 배지는 기존 회색을 쓴다.
- 키·몸무게 측정은 위쪽 키·몸무게 탭에서 확인하며 기록 목록·유형 카드에는 포함하지 않는다.

| 확인 창 | 가운데 카드, 제목 + 설명 + 버튼 2개(왼쪽 취소, 오른쪽 실행) |
| 안내 창 | 확인 창과 같은 카드, 버튼은 가로 전체 [확인] 하나. 고를 것 없이 알리기만 할 때 |
| 바텀 시트 | 위쪽 손잡이 막대, 위 모서리 24px |
| 빈 상태 | 연보라 아이콘 상자 + 안내 문구 + 기록하기 버튼 |
| 유형별 개수 | 성장 > 기록 위쪽, 같은 폭 카드 4개(단어·행동·표정·처음 먹은 음식). 모바일 52px 한 줄형·넓은 PC 세로형. 누르면 그 유형만 보기, 기간 유지, 선택 상태는 2.4·배치는 5.2 |
| 계획 칸 | 1.5px 점선 `soft-text` 테두리 + "예정" 배지 |

- 아이콘이 있는 검색 입력칸은 기본·포커스·오류 상태 모두 글자가 같은 위치에 오도록 왼쪽 여백을 유지한다. 테두리가 1px에서 2px로 바뀌면 여백을 1px 줄여 글자 위치를 보정한다.

## 쇼핑 시안 반영 (2026-11-23)

승인된 [쇼핑목록.md](쇼핑목록.md)를 따른다. 기존 회백색·보라 토큰과 20px 카드·FormPage 입력·ChoiceChips 필터를 재사용한다. 살 물건/자주 사는 물건 탭 아래 전체·6개 카테고리를 줄바꿈해 배치한다. 선택은 연보라 배경·보라 2px 테두리다. 어젯밤 수면 다음에 사야 할 물건 카드를 둔다. 다른 요약과 같은 16px/700 제목·20px 아이콘·20px 모서리·16px 패딩을 적용하고, 제목 아래에 보라 글자와 오른쪽 화살표의 “살 물건 N개 ›” 링크를 둔다. 개별 물건은 홈에 나열하지 않고 클릭해 상세 목록에서 확인한다. 나머지 카드 순서는 유지한다. 모바일에서는 준비 탭에서 사야 할 물건을 연다. 환경 설정은 홈과 아이 정보 헤더에서 연다. PC 메뉴는 준비와 설정을 모두 제공한다.

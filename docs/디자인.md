## 1. 개요

### 1.1 기준

- 디자인 시안(claude.ai 캔버스, 비공개): https://claude.ai/artifact/DoQQ31jnCJUKzDzujcibRo
- 시안은 화면 구성과 동작을 보여 주는 참고 자료이고, **색·글자·간격 같은 수치는 이 문서가 기준**이다. 시안과 이 문서가 다르면 이 문서를 따른다.
- 화면별 요구사항은 `docs/기능요구사항서.md`를 따른다. 시안은 기능요구사항서의 와이어프레임을 대체한다.

### 1.2 방향 (D-01)

| 항목 | 결정 |
| --- | --- |
| 분위기 | 밝고 귀여운 색감 + 깔끔한 플랫 디자인. 그림자·그라데이션 최소화, 둥근 모서리, 넉넉한 여백 |
| 색 조합 | C안 라벤더·피치 |
| 글꼴 | Pretendard (시안은 도구 제약으로 Noto Sans KR로 표시) |
| 아이콘 | Lucide (시안은 비슷한 모양으로 그린 임시 아이콘) |
| 다크 모드 | 지원. 기본은 기기 설정을 따르고, 설정 화면에서 라이트/다크를 직접 고를 수 있음 |
| 화면 크기 | 모바일 우선 반응형. 768px 기준으로 모바일·PC 레이아웃 전환 |

### 2.3 유형 색 (구분 용도)

배지·기록 카드 아이콘처럼 **기록의 종류를 구분할 때만** 쓴다. 선택 상태에는 쓰지 않는다.

| 유형 | 배경 / 글자 (라이트) | 배경 / 글자 (다크) |
| --- | --- | --- |
| 단어 | `#ECE7FF` / `#4A35A6` | `#2E2747` / `#CBBBFF` |
| 행동 | `#FFE6D6` / `#9A4515` | `#45291C` / `#FFC4A3` |
| 표정 | `#DDF4EC` / `#1D6B59` | `#1E3D35` / `#9BE8D3` |
| 놀이 | `#FFF0C2` / `#8A6800` | `#3B331C` / `#FFE08A` |
| 처음 먹은 음식 | `#F1EFF6` / `#4F4B5C` | `#2A2733` / `#D6D2E0` |
| 키·몸무게 | `#E3EEFF` / `#1C5797` | `#1D3350` / `#B9D6FF` |
| 음식 "먹어봄" 상태 | `#DDF4EC` / `#1D6B59` | `#1E3D35` / `#9BE8D3` |

### 2.4 색 사용 규칙

- **선택 상태는 모두 보라색**: 연보라(`soft`) 배경 + 보라(`primary`) 2px 테두리 + 진보라(`soft-text`) 글자. 하단 탭, 유형 선택, 필터 칩, 정렬, 기간 선택 모두 같다.
- **색만으로 구분하지 않는다**: 알러지·주의는 경고 아이콘 + "주의" 글자, 유형은 아이콘 + 이름, 계획 칸은 점선 + "계획" 배지를 함께 쓴다.
- **명도 대비**: 글자는 배경과 4.5:1 이상. 놀이 글자색 `#8A6800`은 대비 기준 안에서 가장 연하게 조정한 값이다.

## 3. 글자

| 용도 | 크기 | 굵기 |
| --- | --- | --- |
| 화면 제목 (PC) | 28px | 700 |
| 화면 제목 (모바일) | 24px | 700 |
| 카드·시트 제목 | 17~18px | 700 |
| 본문, 입력값 | 16px | 400 |
| 보조 설명, 목록 부가 정보 | 14px | 400 |
| 배지, 캡션, 입력칸 라벨 보조 | 12~13px | 400~700 |
| 하단 탭 라벨 | 12px | 500 (선택 700) |

- 입력칸 글자는 16px 이상으로 한다 (iOS에서 16px 미만이면 입력 시 화면이 확대됨).

## 4. 간격·모서리·크기

| 항목 | 값 |
| --- | --- |
| 간격 단위 | 4, 8, 12, 16, 20, 24, 32px |

| 모서리 | 입력칸 12px, 버튼 14px, 카드 18~20px, 바텀 시트 위쪽 24px, 배지·칩 999px(완전 둥근) |
| 버튼 높이 | 기본 48px, 화면 하단 주요 버튼 52px |
| 터치 영역 | 최소 44 × 44px |
| 아이콘 | 기본 22px, 버튼 안 20px, 배지 안 11~14px, 선 굵기 2px |

## 5. 레이아웃

| 화면 폭 | 메뉴 | 본문 |
| --- | --- | --- |
| 768px 미만 (모바일) | 하단 탭 5개 (높이 76px) | 한 열 |
| 768px 이상 (PC) | 왼쪽 세로 메뉴 (폭 240px) | 최대 폭 960px, 가운데 정렬. **주간 식단만 1,280px** |

- 하단 탭·왼쪽 메뉴: 홈 / 성장 / 타임라인 / 식사 / 설정
- 성장 탭 안: 키·몸무게 / 단어 / 수면 (상단 탭)
- 식사 탭 안: 주간 식단 / 음식 목록 / 레시피 (상단 탭)
- 목록 화면의 추가 버튼: 오른쪽 아래 떠 있는 60px 버튼 (하단 탭 위 20px)
- 입력은 화면 전환(발달·수면·레시피 편집) 또는 아래에서 올라오는 시트(키·몸무게, 식단 칸, 알러지 지정)를 쓴다.

## 6. 공통 컴포넌트

| 컴포넌트 | 기준 |
| --- | --- |
| 기본 버튼 | `primary` 배경 + `on-primary` 글자 |
| 보조 버튼 | `soft` 배경 + `soft-text` 글자 (취소 등) |
| 외곽선 버튼 | 투명 배경 + `line` 테두리 |
| 삭제 버튼 | `danger` 배경 + `on-danger` 글자 |
| 입력칸 | `surface` 배경, `line` 1px 테두리. 포커스는 `primary` 2px, 오류는 `danger` 2px |
| 오류 문구 | 입력칸 바로 아래, `danger` 색, 원 안 느낌표 아이콘 |
| 글자 수 | 라벨 오른쪽에 "5 / 30" |
| 저장 알림 | 화면 아래 가운데, 둥근 알약 모양, 체크 아이콘 + "저장했어요", 2초 |
| 네트워크 오류 | `danger-soft` 배너 + "다시 시도" 버튼 |
| 확인 창 | 가운데 카드, 제목 + 설명 + 버튼 2개(왼쪽 취소, 오른쪽 실행) |
| 바텀 시트 | 위쪽 손잡이 막대, 위 모서리 24px |
| 빈 상태 | 연보라 아이콘 상자 + 안내 문구 + 기록하기 버튼 |
| 계획 칸 | 1.5px 점선 `soft-text` 테두리 + "계획" 배지 |

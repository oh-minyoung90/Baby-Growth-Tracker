# 보안·홈 화면 설치·운영 배포 점검

2026-11-14 · T-34 구현 및 로컬 검증 결과. 운영 배포(T-35)는 아직 진행 전이다.

## 구현한 내용

| 항목 | 적용 내용 |
| --- | --- |
| 보안 헤더 | `public/_headers`: 모든 정적 응답에 `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer` |
| 설치 정보 | `public/manifest.webmanifest`: 고정 앱 ID·시작 주소·범위 `/`, 한국어, 이름·설명, `standalone` 표시 |
| 홈 화면 아이콘 | 앱 메뉴와 같은 Lucide 새싹·디자인 색상. PNG 192/512px, 불투명 Apple 180px, maskable 중앙 안전 영역. favicon도 새싹으로 통일 |
| iOS 정보 | HTML에 Apple 아이콘·앱 이름·단독 실행·상태 표시줄 설정 연결 |
| 개인정보 오류 출력 | React 루트와 Router 오류 콜백은 `reportUnexpectedError`를 공유한다. 원본 Error·cause·stack·기록 내용·서명 URL 대신 고정 문구만 출력한다. 화면은 기존 일반 오류 안내 유지 |
| 오프라인 | 설계 R22에 따라 Service Worker·오프라인 캐시를 추가하지 않는다. 홈 화면에 설치해도 데이터 이용에는 인터넷이 필요하다 |

아이콘은 미리 생성해 커밋한다. 빌드·CI에서 브라우저를 설치하거나 아이콘을 다시 만들지 않는다.
디자인 토큰 또는 Lucide 버전을 변경해 아이콘을 갱신할 때만 실행한다.

```bash
nvm use 24
npx playwright install chromium
npm run icons
# 설치된 Chrome을 쓸 때
npm run icons -- --chrome
```

- [x] 검증 서버에서 iframe 삽입 차단, 외부 요청의 Referrer 생략, 보안 헤더·MIME과 하위 경로 새로고침 확인
- [x] Service Worker 미등록 확인

Cloudflare Wrangler 4.162.0이 `_headers`의 유효한 규칙 1개를 읽었다. 다만 현재 macOS 13.3에서는
최소 13.5가 필요한 Workers 런타임이 실행되지 않았다. 따라서 실제 Cloudflare 응답 검증은 완료로
표시하지 않는다. 로컬에서는 빌드된 `dist/_headers`를 같은 응답 헤더로 적용한 Vite 미리보기 서버에서
브라우저 동작을 확인했다. 일반 `npm run dev`·`npm run preview`는 `_headers`를 자동 적용하지 않는다.

전체 `npm audit`에는 개발용 ESLint/TypeScript 검사 도구의 `minimatch` 관련 moderate 경고 9건이
남아 있다([GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249)). 운영 번들에는
포함되지 않는다. 자동 제안은 TypeScript 검사 도구의 버전 하향을 포함하므로 강제 적용하지 않았다.
개발 도구의 호환 가능한 수정 버전을 후속 유지보수에서 확인한다.

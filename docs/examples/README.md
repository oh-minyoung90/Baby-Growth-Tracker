# 백업·복원 예시 이미지

`backup-example-photo.png`는 가명 데이터로 만든 앱 화면 캡처입니다. 실제 아이 사진이나 외부 사진은 사용하지 않았습니다. 레시피 사진 선택과 JSON 백업·복원 동작을 확인할 때 사용할 수 있습니다.

1. 식사 → 레시피에서 예시 레시피를 만들고 이 PNG를 사진으로 선택합니다.
2. 설정 → 데이터 내보내기로 JSON을 받습니다. JSON에는 사진 경로가 있고 이미지 파일 자체는 없습니다.
3. 백업 파일을 선택해 내용을 확인하고 가져옵니다. 사진 파일이 같은 계정의 저장소에 남아 있으면 다시 표시됩니다.
4. 사진 파일이 없는 경우에는 레시피 화면에 사진 없음이 표시됩니다. JSON만으로 사진 파일이 복구되지는 않습니다.

## 실제 화면 예시

- [예시 이미지를 사진으로 첨부한 레시피](backup-recipe-with-photo.png)
- [저장소 사진 파일이 없을 때의 레시피](backup-recipe-without-photo.png)

동작 검증 중 생성한 테스트 계정 데이터는 원래 상태로 복원하며, 예시 이미지 파일은 이 폴더에 남깁니다.
